## 4. 安全链

安全过滤器采用小型、显式、可独立测试的组合方式：

1. 校验动作时间和输入新鲜度。
2. 限制动作发出频率。
3. 检查工作空间和关节位置边界。
4. 检查关节速度、笛卡尔速度和关节加速度。
5. 必要时调用注入式 IK 求解器。
6. 由过滤链统一记录通过、拒绝和具体拒绝来源。

部署侧应根据机器人型号组装限制值，避免把 UR 或 RealMan 的硬件参数硬编码到通用包中。

## 5. 看门狗与恢复

看门狗状态为 `HOLDING`、`RECOVERING` 和 `ACTIVE`：

- VR 输入或机器人状态过期时立即进入保持。
- 速度/扭量控制在失联瞬间生成一次显式零动作，随后保持；位置控制直接保持。
- 恢复要求 VR 与机器人状态序列都前进，并完成规定数量的恢复采样。
- 恢复后必须显式确认新的遥操作参考，才允许重新进入 `ACTIVE`。
- 过期决策和不可比较、明显来自未来的时间戳会被拒绝。
- 输出序列单调递增，确保零动作或保持动作不会被执行器误判为旧命令。

组合运行时时，看门狗应位于普通动作过滤链之后，使安全保持动作不会被新鲜度或频率过滤器阻断。
